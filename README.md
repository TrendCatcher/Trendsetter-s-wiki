# Trendsetter's Wiki (Powered by P-Reinforce)

**P-Reinforce**는 Andre Karpathy의 LLM-Wiki 아키텍처와 강화학습(RL) 이론을 결합한 지식 자동화 에이전트 시스템입니다. 파편화된 원시 데이터를 실시간으로 모니터링하여, 인간의 개입 없이 스스로 지식을 분류, 폴더링하고 상호 연결된 거대한 '외부 뇌(Second Brain)'를 구축합니다.

---

## 🚀 Core Mission

1. **실시간 지식화**: `00_Raw/` 폴더에 입력되는 모든 원시 데이터를 실시간 모니터링하여 구조화된 지식으로 변환합니다.
2. **자가 진화 폴더링**: 고정된 폴더 구조에 얽매이지 않고, 지식의 맥락에 따라 스스로 '폴더 트리'를 설계하고 확장합니다.
3. **거대 외부 뇌 구축**: 파편화된 지식들을 `[[쌍방향 링크]]`로 촘촘하게 엮어 거대한 지식 네트워크를 형성합니다.
4. **타임라인 보존**: 변경되는 모든 지식을 즉각 GitHub에 커밋하여 지식의 진화 과정을 영구히 보존합니다.

---

## 🧠 강화학습(RL) 기반 구조화 로직

지식 배치 및 분류 시 아래의 보상 함수(Reward Function)를 극대화하는 방향으로 동작합니다.

$$R = w_1(\text{Categorization Accuracy}) + w_2(\text{Graph Connectivity}) + w_3(\text{User Satisfaction})$$

- **상태(State) 분석**: 현재 `10_Wiki/` 하위의 폴더 트리와 `20_Meta/Graph.json`을 읽어 지식의 지형도를 파악합니다.
- **분류(Action)**: 유사도 85% 이상 시 기존 폴더에 배치하며, 새로운 개념 등장 시 상위 개념을 도출해 새 폴더를 생성합니다. 폴더 내 파일이 12개를 초과하면 세분화(Refactoring)를 진행합니다.
- **정책 업데이트**: 사용자의 피드백(문서 이동, 수정, 칭찬 등)을 수집하여 `20_Meta/Policy.md`를 갱신하고, 다음 분류 시 즉각 반영합니다.

## 📂 폴더 구조 (Directory Structure)

본 위키는 다음과 같은 표준 폴더 구조를 따릅니다.

- **`00_Raw/`**: [불변] 사용자로부터 입력된 가공되지 않은 모든 원시 데이터 보관소
- **`10_Wiki/`**: [자동 구조화] 에이전트가 RL 정책에 따라 관리하고 성장시키는 지식 층
  - `🛠️ Projects/`: 목표 중심 (현재 진행 중인 일, 프로젝트별 요약)
  - `💡 Topics/`: 개념 중심 (스스로 분류한 학문/주제)
  - `⚖️ Decisions/`: 의사결정 중심 (판단과 기록)
  - `🚀 Skills/`: 실행 중심 (프롬프트, 워크플로우 패턴)
- **`20_Meta/`**: [시스템] 지식 엔진의 두뇌 데이터 (`Graph.json`, `Policy.md`, `Index.md`)
- **`.github/`**: GitHub Sync 설정 및 자동화 워크플로우

## 💡 사용자 가이드 (피드백 주기)

당신이 던지는 피드백 한마디가 P-Reinforce의 신경망을 자극하고 진화시킵니다!
- **칭찬**: "이 폴더 분류 완벽해." -> 해당 주제의 유사도 가중치가 상승합니다.
- **수정**: "이건 '코딩'이 아니라 '비즈니스'로 옮겨줘." -> 주제 간 경계선(Boundary Shift)을 재설정합니다.
- **방치**: 만들어진 구조를 계속 사용하면, 암묵적 보상으로 간주되어 정책이 고착(안정화)됩니다.
