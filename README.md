# 뉴베이스 1분 인터랙티브 온보딩 패스

대표님·실무진 검토용 전달 묶음입니다.

## 시작하기

`index.html`을 브라우저에서 열면 됩니다. 인터넷 연결이나 별도 프로그램이 필요하지 않습니다.

- 본문의 `V1 ↗`, `P1 ↗` 같은 근거 버튼을 누르면 해당 주장, 원문 위치, 해석의 경계를 볼 수 있습니다.
- PDF 근거는 모달 안의 `강조 표시된 첨부 PDF n쪽 열기`를 누르면 강조된 위치가 있는 `evidence.pdf`로 열립니다.
- `FLOW PROTOTYPE`은 실제 VR 연동 전인 2D 흐름 시연입니다. `도움이 필요해요`, `바로 실습`, 단계 전환을 직접 확인할 수 있습니다.

## 포함 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 대표님·실무진 검토용 인터랙티브 기획안 |
| `concept.md` | 같은 내용의 읽기·수정용 원문 |
| `evidence.pdf` | 제공 PDF의 근거 문구를 강조한 사본 |
| `evidence.json` | 주장별 원본 위치·해석 경계 데이터 |
| `thinking-card.md` | 오지민의 최초 생각과 AI 제안을 분리하는 사고 카드 |
| `observation-sheet.md` | 첫 조작·두 번째 독립 사용 관찰표 |
| `agent-contract.md` | 근거·가설·세션 리뷰 agent의 권한·금지·수용 기준 |
| `assets/` | 근거 페이지 미리보기 |

## 전달 범위와 확인 필요

- 면접 음성·전체 자동전사·이력서의 개인 연락처는 포함하지 않았습니다. 전달본에는 원음 확인이 필요한 시간 구간의 요약만 있습니다.
- ‘진입장벽 제로’는 컨셉명입니다. 첫 실습 진입률과 두 번째 독립 사용률은 현장 관찰 후 확인할 가설입니다.
- 제품을 아직 직접 사용하지 않았으므로 실제 기기, 현행 튜토리얼, 이벤트 가능 범위와 겹치는 내용은 실무 인터뷰에서 확정합니다.
