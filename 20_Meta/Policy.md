## 현재 분류 가중치 (RL Weights)
$$R = w_1(\text{Categorization Accuracy}) + w_2(\text{Graph Connectivity}) + w_3(\text{User Satisfaction})$$

| 가중치 | 현재 값 | 업데이트 이유 |
|:---|:---:|:---|
| $w_1$ (분류 정확도) | 0.40 | 초기값 |
| $w_2$ (그래프 연결성) | 0.35 | 초기값 |
| $w_3$ (사용자 만족도) | 0.25 | 초기값 |

## 카테고리 경계 규칙 (Boundary Rules)

### Skills
- **포함 기준**: 반복 사용 가능한 실행 패턴, 커맨드 시퀀스, 워크플로우, 프롬프트 템플릿
- **예시**: Local LLM API curl 패턴, @local 라우팅 규칙

### Topics
- **포함 기준**: 분석 결과물, 개념 정리, 외부 지식의 내재화
- **예시**: 글쓰기 스타일 분석, 헬스케어 패러다임 요약

### Projects
- **포함 기준**: 목표가 있고 결과물(초안, 파일, 앱 등)이 예상되는 진행 중 작업
- **예시**: Life GPS 블로그 시리즈 기획

### Decisions
- **포함 기준**: 특정 시점에 'A vs B' 중 선택하고 그 근거를 남긴 기록
