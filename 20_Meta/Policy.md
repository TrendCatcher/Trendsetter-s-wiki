# P-Reinforce 지식 관리 정책

버전 2.0 · 수정일 2026-09-10 · 문서 운영 규칙이며 실행 엔진이 아니다.

## 목적과 근거

원본에서 배우고 다음 기획에 활용하되, 사용자를 과거 한 장면으로 고정하지 않는다. 사용자 이해·소통·서로 응원하는 환경을 함께 다룬다. [하리보의 자기 수정](../00_Raw/2026-07-12-%ED%95%98%EB%A6%AC%EB%B3%B4%20%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%20%EB%B3%B5%EA%B8%B0.md), [수업의 설명 실패와 학생 반응](../00_Raw/2026-05-17-%EC%A3%BC%EA%B0%84%20%ED%9A%8C%EA%B3%A0%20%5B5_11~15%5D.md), [응원하는 환경에 대한 바람](../00_Raw/2024-09-01-%5BDiary%5D%20%EC%9A%B0%EC%A3%BC%EC%9D%98%20GPS.md)에 근거한 방향이며, 이번 사용자 요청으로 운영 원칙에 반영했다.

## 주장마다 구분할 것

| 표기 | 의미 | 기록 조건 |
| --- | --- | --- |
| 직접 말한 사실 | 사용자가 해당 날짜에 그렇게 표현했다는 사실 | 원본 경로·구절·날짜·질문 맥락. 발언 내용의 객관적 진실까지 보증하지 않음 |
| 에이전트의 해석 | 원본을 비교해 도출한 패턴·연결·제안 | 근거, 표본 범위, 반례·대안 해석, 추론임을 명시 |
| 현재 확인 필요 | 과거 자기평가·현재 프로젝트 상태·불명확한 저자·근거 부족 | 확인할 항목과 마지막 근거 날짜. 답이 없으면 미확인 유지 |

외부 자료는 별도로 저자·발행일·URL·자료 유형(제안/의견/실험 논문)을 표시한다. 강사의 주장과 AI의 답변을 사용자 발언으로 바꾸지 않는다. 위키가 다른 위키를 반복 인용해도 독립된 원본 증거가 늘어난 것은 아니다.

## 장르와 경험 보존

- 에세이: 인용 출처와 자신의 생각을 나누고 망설임·바람을 남긴다.
- 회고: 당시 기대 → 실제 마찰/실패 → 자기 판단의 수정 → 다음 시도 → 미해결 항목을 남긴다.
- 기술 글: 문제·예제·질문·확인 결과를 남기고, 감정이나 철학적 도입을 강요하지 않는다.
- 강의 필기: 강사 설명·개인 적용·미완성 항목을 분리한다. 필기만으로 사용자의 동의나 전문성을 추정하지 않는다.
- 인터뷰: 사용자 답변만 자기보고로 다루고 시간 범위를 붙인다.

적용 예시는 [장르별 문체 분석](../10_Wiki/Topics/대표님-글쓰기-스타일-분석.md), [하리보 회고](../10_Wiki/Projects/하리보-프로젝트-회고.md)를 따른다.

## 분류와 갱신

| 폴더 | 분류 기준 |
| --- | --- |
| Skills | 반복 사용할 실행 패턴 |
| Topics | 개념·분석·방법론 |
| Projects | 기획·작업·회고. 기획과 구현·검증 상태는 별도 |
| Decisions | 선택의 근거와 당시 협업 선호 |

관련 링크는 이유가 있는 경우에만 만든다. 최소 개수나 연결성 점수를 채우기 위한 링크는 만들지 않는다. 분류 세분화는 탐색 불편과 주제 분화를 근거로 판단한다.

주장의 변경은 이전 해석·새 증거·수정 이유를 남긴다. 과거 사실의 보존과 현재 유효성은 별도다. `last_reinforced`는 기존 호환 필드인 문서 갱신일이며 사실을 재검증한 날짜가 아니다. 근거의 날짜와 검토 범위를 본문에 적는다.

새 문서의 권장 필드: `id`, `tags`, `review_status`, `last_reinforced`. 주장별로 출처·발언자·근거 날짜·해석 여부·미해결 내용을 본문에 기록한다. 근거가 없으면 정확해 보이는 점수를 만들지 않는다.

## 철회한 과장과 수치 규칙

이전 가중합 R = 0.40×분류 정확도 + 0.35×그래프 연결성 + 0.25×사용자 만족도는 측정 정의·학습 로그·검증 데이터가 없는 설계 아이디어였다. 현재 운영 점수나 강화학습 보상으로 사용하지 않는다. 유사도 85%, 파일 12개, confidence 0.6도 검증되지 않은 임계값이어서 자동 판단 기준에서 제외했다.

기존 `confidence_score`는 보정되지 않은 과거 작성 점수다. 정답 확률·사용자 동의·실행 성공률로 해석하지 않는다. 이번에 재작성한 지식 문서는 `null`로 바꾸고 근거 상태를 본문에 표시했다. 미검토 문서의 값은 과거 데이터로 남겨두되 비교·평가에 사용하지 않는다.

침묵·방치·계속 사용을 승인으로 간주하지 않는다. 명시적 피드백만 승인 또는 수정 근거로 기록한다. Git push 성공은 전송 성공일 뿐 지식의 신뢰도를 높이지 않는다.

## 실행 및 Git

현재 방식은 사용자의 요청에 따라 에이전트가 파일을 읽고 수정하는 것이다. 실시간 감시·자동 학습·자동 동기화는 확인되지 않았다. 현재 요청 범위에서 원본은 수정하지 않는다.

변경 후 출처 링크·인덱스·그래프를 점검한다. 커밋은 변경 범위를 확인하고 작업 파일만 포함한다. `git add .`를 일괄 실행하지 않는다. 원격 push는 사용자 검토·승인 후 수행한다.
