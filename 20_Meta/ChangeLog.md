# 지식 변경 기록

## 2026-09-10 | 원본 근거·장르·관점 변화 보완

### 요청 근거

현재 대화에서 사용자가 장르별 차이, 과장 최소화, 망설임·실패·관점 변화 보존, 사용자 이해·소통·응원, 직접 발언/해석/현재 확인 필요 구분을 요청했다. 이 문장은 에이전트의 요청 요약이며 새 Raw 원문으로 취급하지 않는다. 최종 결과의 확인과 git push 승인은 아직 받지 않았다.

### 수정 내용

- README: 원본에 근거한 목적과 자기 수정 사례, 사실·해석·확인 필요를 표시.
- 문체 분석: 선택한 11개 원본의 장르와 발언자를 구분. 전체 Raw 분석이라는 주장과 고정 문체 일반화를 철회.
- 하리보: 팀원에 대한 답답함뿐 아니라 자기 관점·전달 방식의 재검토 복원.
- 모루틴: 기획 후보와 후기의 미해결 과제를 연결. “페르소나 확립”과 원인·효과 일반화 교정.
- Hermes: 과거 자기평가와 선호를 당시 자기보고로 한정.
- Life GPS: 에이전트의 콘텐츠 제안을 사용자의 채택·현재 개인 사실과 구분.
- Karpathy·Agent AI: 설계 제안·외부 사례와 구현·성과를 구분.
- 운영 명세·Policy: 임의 RL 점수, 강제 링크, 침묵 승인, push 성공 보너스를 판단 기준에서 제외. 이전 정책 이력은 과거 기록으로 유지.
- Index·Graph: 이번 수정 상태를 맞추고 미검증 점수·관계의 의미를 명시. 노드 21개·관계 19개 유지.
- Research-LLM-Wiki: 공개 논의·원문·논문과 공식의 적용 범위를 구분. 검색·평가 구현은 제안만 기록.

### 검토 범위와 남은 일

Raw 85개 전체와 모든 Wiki의 사실 정확성을 전수 감사하지 않았다. 기존 다른 기획의 효능·구현·채택 상태와 출처 링크는 별도 검토가 필요하다. 기술 글의 코드 정확성도 문체 분석만으로 보증하지 않는다. 이 작업에서는 연구에서 소개한 검색·평가 알고리즘을 실행하지 않았다.

사용자 확인이 필요한 사항: 수정된 소개와 해석이 본인의 의도에 맞는지, 과거 목표·협업 선호·콘텐츠 기획이 현재도 유효한지. 확인 전에는 상태를 확정하지 않는다.

## 2026-09-12 | 사용자 검토 및 push 승인

사용자가 현재까지의 변경을 검토하고 push를 요청했다. README에서 아직 완전히 이해하지 못한 부분은 이후 직접 고쳐나가겠다고 밝혔다. 이는 현재 문서 변경의 게시 승인이고, 모든 해석·과거 목표의 현재 유효성·연구 제안을 사실로 확정하는 승인은 아니다. 이번 커밋 범위는 위 작업의 문서 14개이며, 별도 Raw 및 Velog 수집 데이터 변경은 포함하지 않는다.
