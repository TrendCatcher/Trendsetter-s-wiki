# [[디지털-헬스케어-3대축과-데이터-생태계]]

## 📌 한 줄 통찰 (The Karpathy Summary)
> 디지털 헬스케어는 질병 치료(Illness), 일상 건강관리(Wellness), 병원 기반 시설(Infra)의 3대 축으로 작동하며, 단순 데이터 조회를 넘어 AI 기반의 '발병 및 악화 예측'과 '표준 데이터 연계'가 결합될 때 실질적인 시장 가치를 창출한다.

## 📖 구조화된 지식 (Synthesized Content)

### 1. 디지털 헬스케어의 정의
> 데이터와 IT 기술을 활용하여 개인의 건강관리, 질병 예방, 치료 등의 의료 및 웰니스 서비스를 제공하는 융합 산업.

### 2. 산업 구조 3대 축 (3-Pillar Framework)
```
┌─────────────────────────────────────────────────────────────┐
│                 디지털 헬스케어 생태계 3대 축                    │
├─────────────────┬─────────────────────────┬─────────────────┤
│   1. Illness    │       2. Wellness       │    3. Infra     │
│   (치료 및 의료)  │      (예방 및 일상)       │   (병원/의료기반)  │
├─────────────────┼─────────────────────────┼─────────────────┤
│ • 의료용 진단기기 │ • 정신건강 관리 솔루션    │ • EMR / OCS     │
│ • 디지털 치료제   │ • 개인 맞춤형 영양/운동    │ • PACS 영상전송 │
│ • 의사-환자 매칭  │ • 만성질환 생활습관 관리   │ • 클라우드 EMR  │
└─────────────────┴─────────────────────────┴─────────────────┘
```

### 3. AI 헬스케어의 진화 방향: 분석을 넘어 '예측'으로
- **단순 분석의 한계:** 현재 수치를 대시보드로 보여주는 수준(과거 회고)은 사용자 행동 변화를 이끌어내지 못함.
- **예측 중심 패러다임:** 뷰노(Vuno), 루닛(Lunit) 등의 사례처럼, 과거 및 실시간 데이터를 종합하여 **"미래 발병 가능성 및 질환 악화 시점"**을 사전에 예측하여 선제적 개입(Preemptive Intervention)을 가능하게 하는 것이 핵심 경쟁력.

### 4. 데이터 밸류체인과 맞춤형 큐레이션 (원스글로벌 사례)
- 의약품 데이터(DUR), 건강검진 데이터, 라이프로그 데이터를 표준화된 온톨로지로 연결해야만 진정한 개인 맞춤형 처방 및 서비스 추천이 가능함.

## ⚠️ 모순 및 업데이트 (Contradictions & RL Update)
- **접근법 수정:** 헬스케어 기획 시 막연히 'AI 헬스케어'라는 단어를 쓰기보다, 본 서비스가 Illness/Wellness/Infra 중 어느 영역에 속하며 어떤 데이터 파이프라인을 통해 '예측 가치'를 전달하는지 명확히 규정해야 함.
