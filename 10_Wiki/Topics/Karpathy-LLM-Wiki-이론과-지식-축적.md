# Karpathy LLM-Wiki 이론과 지식 축적

## 직접 기록된 관심

[2026-06-23 원본 메모](../../00_Raw/2026-06-23-%5BDraft%5D-%5BKarpathy%5D%20LLM-wiki%20%EC%9D%B4%EB%A1%A0.md)는 읽은 내용을 Markdown 지식으로 축적하는 구조와 ingest·query·lint를 정리했다. 이는 사용자의 학습 기록이며 원문의 모든 주장에 대한 실증 검증은 아니다.

## 외부 원문 확인 · 2026-09-10

[Karpathy의 LLM Wiki Gist](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)는 원본·위키·규칙을 나누는 설계 제안이다. 특정 구현이나 검증된 최적 수학식이 아니다. 원문에는 출처 인용, 모순·오래된 주장 점검과 사용자 참여가 포함된다.

## 이 프로젝트의 해석과 적용

- 원본에 돌아갈 수 있게 요약과 출처를 연결한다.
- 실패·자기 수정·미해결 문제를 합성 과정에서 지우지 않는다.
- 위키는 재사용 가능한 중간 기록이다. 위키에 적혔다는 이유로 사실이 확정되거나 사용자가 동의한 것은 아니다.

검색과 축적을 배타적인 선택으로 다루지 않는다. 위키를 검색하고 필요하면 Raw를 다시 읽는 방식으로 결합할 수 있다. 토큰·시간 절약은 실제 비교 전에는 가설이다.

## 이전 해석의 수정

이전의 “모든 RAG는 매번 전체 문서를 읽는다”, “위키는 항상 토큰을 절약한다”, “RL 엔진이 공식 구조다”라는 취지의 일반화를 철회한다. 원문에 없는 보상함수·유사도 85%·폴더 12개 기준은 프로젝트의 과거 아이디어였다. [정책](../../20_Meta/Policy.md)에서 판단 기준으로 사용하지 않도록 수정했다.

## 현재 확인 필요

이 저장소의 자동 감시·학습·동기화, 질의 성능과 유지 비용은 검증하지 않았다. 최근 공개 논의와 평가 방법은 [연구 검토](../../20_Meta/Research-LLM-Wiki.md)에 분리했다.
