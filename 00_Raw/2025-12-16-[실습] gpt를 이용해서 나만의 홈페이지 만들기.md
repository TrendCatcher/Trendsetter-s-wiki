# 🤖 고등학생 코딩 실습: "GPT야, 내 코드를 부탁해!" 

> **부제: 프롬프트 한 줄로 시작하는 나만의 웹사이트 만들기**

안녕하세요! 오늘은 고등학생들이 코딩에 흥미를 느낄 수 있도록, **ChatGPT를 활용한 실습 예제**를 공유하려고 합니다.  
복잡한 문법 공부보다, 내가 말하는 대로 화면이 바뀌는 경험이 학생들에게는 훨씬 강력한 동기부여가 됩니다.

학생들이 직접 복사해서 GPT에게 시켜볼 수 있는 **"마법의 주문(프롬프트)"** 모음집입니다.  
난이도별로 준비했으니, 학생들 수준에 맞춰서 활용해보세요!

---

## 🟢 1단계: 디자인 바꾸기 (CSS)
**"내 웹사이트는 내가 꾸민다!"**  
코드의 로직을 건드리지 않고, 디자인(CSS)만 수정해서 시각적인 즐거움을 주는 단계입니다.

### 🎨 예시 1: 사이버펑크 스타일
어두운 배경과 네온 사인을 좋아하는 학생들을 위한 프롬프트입니다.

```text
지금 style.css를 수정해서 웹사이트를 '사이버펑크 다크 모드'로 바꿔줘.
배경은 아주 어두운 남색(#0a0a2a)으로 하고, 카드는 반투명한 검은색으로 해줘.
제목과 버튼에는 형광 네온 블루(#00f3ff) 색상과 빛나는 효과(text-shadow, box-shadow)를 넣어줘.
```
## 🟡 2단계: 기능 추가하기 (HTML + Python)
### 🍔 예시 1: 야식 메뉴 고르기 (드롭다운)
```
회원가입 창에 '가장 좋아하는 야식'을 고를 수 있는 메뉴를 추가하고 싶어.
이름 입력창 아래에 '치킨', '피자', '떡볶이' 중에 하나를 선택하는 드롭다운(<select>)을 만들어줘.
그리고 결과 화면에서 'OOO님은(는) 피자를 좋아합니다!' 라고 문장이 나오게 app.py랑 home.html을 수정해줘.
```

### 🎨 예시 2: 감성 다이어리 스타일
```
웹사이트 디자인을 '따뜻한 감성 다이어리' 느낌으로 바꿔줘.
배경은 연한 베이지색 종이 질감 느낌이면 좋겠어.
폰트는 손글씨 느낌의 둥근 폰트로 바꾸고, 입력창과 버튼은 파스텔 핑크색으로 둥글게 만들어줘.
전체적으로 여백을 넉넉하게 줘서 편안한 느낌을 줘.
```

## 🔴 3단계: 로직 & 데이터 (Python 심화)
```
지금은 서버를 끄면 입력한 이름이 다 사라지잖아.
입력받은 데이터를 guests.csv라는 엑셀 파일에 자동으로 저장되게 만들어줘.
그리고 웹사이트를 새로고침 하거나 서버를 다시 켜도, 파일에 저장된 목록을 읽어와서 화면에 그대로 보여주게 코드를 수정해줘.
```

### 💾 예시 1: 엑셀 파일로 영구 저장하기
```
지금은 서버를 끄면 입력한 이름이 다 사라지잖아.
입력받은 데이터를 guests.csv라는 엑셀 파일에 자동으로 저장되게 만들어줘.
그리고 웹사이트를 새로고침 하거나 서버를 다시 켜도, 파일에 저장된 목록을 읽어와서 화면에 그대로 보여주게 코드를 수정해줘.
```

### 🚫 예시 2: 욕설 필터링 & 중복 방지
```
똑같은 이름을 두 번 입력하면 '이미 등록된 이름입니다!' 라는 경고 메시지(alert)를 띄우고 저장이 안 되게 막아줘.
그리고 만약 이름에 '바보', '멍청이' 같은 나쁜 말이 들어가면 '예쁜 말을 씁시다' 라고 알려주고 저장을 거부하는 기능을 추가해줘.
```
