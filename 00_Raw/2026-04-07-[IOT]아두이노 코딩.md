# 아두이노란?
> 사용하기 쉬운 HW 와 SW를 결합한 오픈소스 전자 프로토타이핑 플랫폼

- 입력과 출력으로 변환하는 **마이크로 컨트롤러 보드**가 핵심
	- 센서나 버튼의 신호를 읽는 **입력**
	- LED를 켜거나 모터를 움직이는 **출력**
- 방대한 **오픈소스 라이브러리**가 있어 **소프트웨어와 하드웨어 교육용**을 탁월
- 일상용품부터 복잡한 과학 기기 제작까지 **폭넓게 활용**

# Mblock이란?
>  오픈 소스 그래픽 프로그래밍 플랫폼

- 복잡한 코딩 대신 드래그 앤 드롭방식의 블록 코딩을 사용
- 컴퓨터 게임 제작부터 **아두이노 기반 로봇 제어**까지 폭넓게 활용가능 
 ## mBlock의 주요 사용 및 활용법
 ### 장치 연결 및 준비
 1. mBlock 실행 후 장치 라이브러리에서 'Arduino Uno' 보드를 추가
 2. 아두이노 기기와 케이블을 연결
 3. **접속 가능한 모든 기기 표시**'를 체크하여 하드웨어를 연동
 
 ### 기초 출력 제어
 
 - 디지털 핀의 출력상태(High/Low)를 블록으로 설정
 - LED를 번갈아 가며 켜거나, 부저를 제어(피아노 음계)

- 센서 기반 상호작용
	- 조도센서의 아날로그 값을 읽어들임. 
    - 값에 따라 불이 켜지고 꺼지는 놀이터 가로등 불빛 원리 체험 가능

> 참고: 조도센서의 물리적 작동 및 신호 변환

- 다기능 쉴드에는 빛의 세기에 따라 **저항값이 변하는 CDS센서가 포함**되어, 이 센서가 아두이노의 아날로그 입력 핀인 **A1에 연결**됨
- 전압변화: 주변의 빛의 밝기 변화에 따라 센서의 **저항**이 달라지고, **전압**이 변함 (V=IR)
- Analog값 생성: 아두이노 내부의 ADC(Arduino-to-Digital)는 연속적인 전압 신호를 받아0~1023사이의** 아날로그 값으로 변환**
### 심화활용 및 확장
**DHT11센서** (multi-function arduino shield)를 추가하여 실시간 온습도를 시리얼 모니터로 확인하는 **디지털 온도계**등으로 활용

### 결론
mblock은 아두이노의 강력한 HW기능과 스크래치의 쉬운 SW환경을 연결해줘 교육용 프로토타이핑 도구로 탁월.

### 다기능 확장 쉴드

> 아두이노 우노 보드 위에 결합하여 사용하는 확장 보드

- **온습도를 측정**하여 **디지털 신호로 출력**하는 전용 센서 부품인 **DHT11**을 포함한 여러 장치를 한곳에 모아놓은 것
- 다기능 쉴드로 인해 선 연결 없이 LED, 조도센서, 부저를 한꺼번에 다룰 수 있음.

> 데이터 성격에 따른 블록 코딩 주의사항

- DHT11센서는 온습도값을 **디지털 신호**로 변환
- 반면, 조도 센서는 **아날로그 신호**를 보냄
- mblock 코딩시 DHT11은 전용 확장 블록

## mblock을 이용한 데이터 읽기/확인

- 핀 읽기 블록: mblock의 핀블록 사용
- 변수 저장: 읽어온 아날로그 값을 더 효율적으로 사용하기 위해 '조도'라는 이름의 변수를 만들어 저장.
- 시리얼 모니터링: 프로그램 실행 중 [시리얼 포트에 (조도)]출력 블록 배치 -> 손가락으로 가려보고 그렇지 않을때 아날로그 수치 변화를 arduino IDE에서 확인가능. 


### 아날로그값을 활용한 스마트 제어
- 비교 연산: '연산' 카테고리의 비교 블록을 사용해
```
아날로그 값 < 기준치
``` 
와 같은 조건을 설정. 

- 임계값(Threshold) 설정: 시리얼 모니터로 확인한 값을 바탕으로 가로등이 켜져야 할 어두운 정도 기준값 판단
- 동작 제어:
	- D9~11, D12, D13번 디지털 핀에 연결된 LED를 High로 설정=> 점등
    - 반대로 수치가 기준치보다 크면 LED를 Low로 설정 => 소등
    
    
    

    


## 궁금했던 점
1. 조도센서를 가리면 낮아지는 출력(시리얼 모니터)은 저항이 낮아져 전압이 낮아지나? 

A. 연속적인 전압을 adc의 핀이 읽어 숫자로 변환하는 값이 낮아져 **아두이노 핀에 입력되는 전압이 낮아진건 맞으나**, 조도센서(CDS)는 빛의 양과 저항이 반비례하므로, 빛을 가리면 저항이 커짐. 따라서 전류는 그대로이므로 저항이 커져 전압이 크게 흐른다.

[놓치고 있는 관점 : 전압 분배]
다기능 쉴드 내부에는 고정 저항과 조도센서가 직렬로 연결된 **전압 분배 회로**를 사용, 전체 전압이 두 저항의 비율에 따라 나누어 걸림. 

어두워짐 => CDS저항 커짐 => 조도 센서(CDS)가 전압 다 가져감 => 고정 저항에 걸리는 전압을 체크하는  **조도센서 — (측정 지점) — 고정저항**의 **<span style= "color:red">측정지점 전압</span>** 하락! (**전압 분배**)
